# Hassan Magdy — Portfolio

موقع بورتفوليو لحسن مجدي، مونتير وموشن جرافيك ديزاينر وجرافيك ديزاينر من إسكندرية، مقيم في دبي.
مبني بـ [Astro](https://astro.build) و[GSAP](https://gsap.com)، وبيطلع صفحات HTML جاهزة وسريعة.

- إنجليزي (الأساسي) على `/`، وعربي على `/ar/`
- الوضع الداكن هو الأساسي، ومعاه زرار للوضع الفاتح
- الصفحات: الرئيسية · Work · About

## الفكرة

الموقع مستوحى من برنامج المونتاج:

- **Program Monitor** في الرئيسية. لو مفيش شوريل، بيشتغل فيه موشن جرافيك معمول بالكود ومتزامن مع التايملاين.
- **تايملاين** تحت الشاشة فيه تراكات ملوّنة. لما تقف بالماوس على كلمة من "Cut. Move. Design." التراك بتاعها بينوّر.
- **تلات ألوان للتلات تخصصات**: بنفسجي للمونتاج، وردي للموشن، وتركواز للتصميم. نفس الألوان مستخدمة في الفلاتر والكروت والخدمات.
- **بلاي هيد بيمشي مع السكرول** في سكشن "المشروع بيمشي إزاي"، وشريط سكرَبر تحت الصفحة (على الكمبيوتر بس) عليه ماركرات للسكاشن.
- **خط Alexandria** عربي ولاتيني، على اسم بلد حسن.

## التشغيل محلياً

```bash
npm install
npm run dev      # http://localhost:4321/
npm run build    # يطلع الموقع الجاهز في dist/
```

## النشر على Hostinger

Hostinger بينسخ المستودع زي ما هو في `public_html` ومش بيعمل build، عشان كده:

- الموقع الجاهز موجود في فولدر `dist/` ومرفوع على المستودع.
- ملف `.htaccess` اللي في الروت بيوجّه كل الطلبات لـ `dist/`.
- أي تعديل في `src/` أو `public/` بيتعمله build تلقائي من GitHub Actions، و`dist/` الجديد بيترفع لوحده.

لما يبقى فيه دومين: حطه في `SITE_URL` في `astro.config.mjs`، وده بيشغّل الـ canonical والـ sitemap.

## التعديل

كل المحتوى في ملفات بيانات، مش جوه الصفحات:

| الملف | فيه إيه |
| --- | --- |
| `src/data/site.ts` | الاسم والتواصل والسوشيال ولينكات السي في والبورتفوليو PDF والبرامج والعملاء |
| `src/data/work.ts` | الشوريل والمشاريع (id من Google Drive، النوع، التخصص، المقاس). `featured: true` تظهر في الرئيسية |
| `src/i18n/ui.ts` | كل النصوص بالإنجليزي والعربي، والخبرة، وعناوين ووصف الـ SEO لكل صفحة |

أي خانة فاضية في `site.ts` (إيميل، واتساب، سي في...) مش بتظهر في الموقع لحد ما تتملي.
أي مشروع من غير `id` بيظهر ككارت ملوّن مكتوب عليه "قريباً".

الفيديوهات والصور بتتعرض من Google Drive مباشرة، فلازم الملفات تفضل متشاركة **Anyone with the link**.
